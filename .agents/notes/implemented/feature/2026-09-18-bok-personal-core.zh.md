# Agent Note: Bok Personal Core 集成

Status: implemented

[English](2026-09-18-bok-personal-core.md) | 中文

## 问题

用户要求将 Bok 完整的关于我功能接入 DSH，包括原有视觉设计和个人记忆操作，而非再实现一套状态机。

## 决策

可选的原生会话事件观察器通过有界后台队列处理新完成的用户文字轮次。它记录完整辅助模型请求，依据原版 Bok 信号契约验证逐字证据，并保留原有学习与审核规则。用户可以持久化暂停观察。它不回填历史，也不授予共享 Vault 发布权限。

经用户批准的 Vault 连接在 Semantic 下增加受保护的导出目录，不搬迁 Personal Core，也不替换 Profile.md。原版 claim 服务继续作为事实来源；适配层私下保留逐条同步基线，要求明确发布与纠正确认，并核对撤回共享的导出。来源 ID 避免导出记录变成新的独立观察。runtime 状态和用户修改恢复副本位于共享 Vault 之外，也不属于 Bok 自身的备份范围。

按需启用的 `ui-personal` 包嵌入固定版本的上游页面和 Python 引擎。DSH slot 外壳在导航切换间保留页面，原版五个视图与对话框保持完整。经过身份验证的 Host 路由只转发 Personal Core 浏览器操作。四个工具通过受限且可撤销的 DSH Agent 凭证调用同一引擎。私人目录位于项目 Vault 和 Git 之外，不导入现有历史。

## 约束

随手记按钮使用现有全局 overlay 槽位，嵌入 Bok 原版纸张窗口，不新增导航页面。用户主动捕获的内容写入 `ideasVaultRoot` 下的 `Ideas/Draft`，不进入私人 Personal Core 或 Agent Knowledge。原文保持不变，不生成种子定义。现有 Vault 保护脚本、经过身份验证的路由、UUID 校验、原子且不覆盖的文件创建及内容绑定的重试检查保护该写入路径。草稿 ID 在请求失败和刷新后保留，浏览器草稿仍使用原版 24 小时有效期。

适配器需要 Python 和 Web server，原版页面保持中文。复用引擎保留确认、单独授权、证据积累、纠正历史、反馈、备份及破坏性遗忘确认，代价是隔离页面和本机进程。固定版本的许可声明与修改文件归属随包发布。自动捕获全部历史和静默提示注入不属于本次改动。

## 验证

Loader 组合测试覆盖身份验证、路由隔离、真实私人存储、受保护主张审核与授权、四个工具、纠正、备份、确认遗忘、凭证撤销与插件销毁，并记录模型可见的隐私收据快照。浏览器检查覆盖五个视图、面板切换与窄屏布局。Host 与 Client 分别进行类型检查。上游个人记忆测试覆盖复用的状态机；当前 Windows 环境缺少创建符号链接所需权限，无法运行其中一个创建符号链接的用例。

## 考虑过的替代方案

重新实现 Personal Core 会复制其审核和凭证规则。要求每个智能体调用观察工具，会让自动采集依赖智能体行为。原生会话事件提供现有扩展点，无需修改智能体循环。历史回填不在本次监控范围内。

## 影响

符合条件的新文字轮次产生一次有界辅助模型请求。队列不持久化，超量时跳过。暂停状态持久化，受保护画像和共享发布仍保留独立用户确认。
