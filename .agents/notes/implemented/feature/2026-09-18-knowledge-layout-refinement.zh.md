# Agent Note: Knowledge 页面布局优化

Status: implemented

[English](2026-09-18-knowledge-layout-refinement.md) | 中文

## Problem

Knowledge 分散的筛选行与宽松间距让有用内容出现得较晚。用户还为条目列表选定了 Bok 的紧凑纸片卡片，同时保留页面其余部分的样式。

## Decision

保留原版背景、标题和层级摘要。选中条目的当前知识区域与全文阅读器共用列表的纸张配色，保留阅读器操作和审批行为。列表卡片参考 [Bok](https://github.com/asen-goat-mine/bok)，采用暖色纸张、纯 CSS 撕边与纹理、交替轻微倾斜及 140ms 悬停上移。标题优先于正文预览；摘要仍可搜索并显示在当前知识区域。刷新与反馈位于页头，筛选集中排列，当前条目与按已有三阶段顺序排列的层级摘要并排显示。搜索、选择、完整时间戳、阅读器操作和审批行为保持不变。

## Alternatives considered

**替换背景或引入新主题。** 改善信息层级不需要这两项改动，替换背景也违背本次要求。

**引入共享集合页面框架。** 本次改动属于一个现有包，CSS Modules 和已有组件足以完成所需布局。

## Consequences

容器查询依据实际面板宽度适配，包括 Files 旁的窄区域。纸张装饰属于伪元素，不会裁掉原生按钮的键盘焦点轮廓。减少动态效果偏好会禁用倾斜与上移。层级摘要保留原版 680ms 悬停序列。组件测试覆盖选择、筛选与阅读器行为；构建后的页面检查响应式布局和键盘访问。不引入 Bok 的存储、运行时或资产，阅读器行为及审批流程保持不变。
