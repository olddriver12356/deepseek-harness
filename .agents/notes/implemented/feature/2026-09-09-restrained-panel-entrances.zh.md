# Agent Note: 克制的面板入场动效

Status: implemented

[English](2026-09-09-restrained-panel-entrances.md) | 中文

## Problem

应用导航需要简短的视觉提示，让用户知道选中的内容已经变化。在信息流刷新、遥测更新或输入期间重复播放这种提示，会干扰阅读。动效还必须遵循减少动态效果的偏好和原生对话框行为。

## Decision

静态 [ui-primitives 库](../../../../packages/client/ui-primitives/README.zh.md#entrance-motion) 通过 `useEntranceMotion` 管理 Anime.js 生命周期。消费方绑定局部 ref，并提供激活状态和标量选择 revision。面板与对话框的入场动画保持短暂；可见卡片批次有数量上限，且只改变 opacity，让现有悬停变换保留控制权。

导航栏动画化选中项的数字，而不是可交互的标签。Knowledge 在显式选择层级时重播卡片；Experts 与 Styles 每次激活只展示一次首次加载的卡片动效。Skills 和 Monitor 在激活时入场。News 每次激活都等待首次成功且可见的信息流加载；请求在隐藏期间完成时，等待重新激活。刷新、查询编辑和实时数值不会触发另一轮入场动画。

原生对话框消费方在 `showModal()` 之后激活动效，并在原生关闭恢复焦点后，通过 `onClose` 清除局部对话框状态。在 `onCancel` 期间清除状态会提前卸载对话框，使浏览器无法将焦点恢复到触发控件。动画清理在完成、中断或减少动态效果偏好变化时恢复内联样式。关闭保持即时。

## Alternatives considered

**独立动画插件：** 展示工具不需要 Cordis 注册、额外服务或新的应用状态所有者。共享静态库为消费方提供统一的生命周期实现。

**持续或数据驱动的动效：** 遥测数字递增、图表扫入、流式文本延迟和刷新驱动的卡片入场会在用户阅读时占用注意力。显式激活与选择变化让动效的用途保持有限。

**延迟退出动画：** 等待退出完成会使 Escape、焦点恢复和快速导航变得复杂。即时关闭让这些交互独立于动画结束时机。

## Consequences

消费方负责异步就绪状态，并在普通数据更新期间保持 revision 稳定。卡片在入场时选取；之后滚动不会动画化更多卡片。Anime.js 增加浏览器依赖，而钩子不引入模型请求、持久化数据或业务订阅。

## Testing

专用[钩子测试](../../../../packages/client/ui-primitives/tests/entrance-motion.client.spec.tsx) 的五项测试通过，覆盖激活、revision 变化、清理、减少动态效果和可见卡片数量上限。News 与 Monitor 测试共 28 项全部通过，覆盖延迟的信息流就绪、隐藏期间完成、刷新抑制和实时投影即时更新。

另外五个消费方包运行 91 项测试：89 项通过，包括全部五项新增动效回归；两项既有 Knowledge CSS 断言与当前工作区的字体大小及背景图不符。调整原生关闭处理后，三个对话框测试套件的 16 项测试全部通过。原生对话框测试确认 `showModal()` 先于动画，且关闭后可即时重开。

Chromium 验证确认打开时输入框获得焦点、Escape 后焦点恢复到触发控件，以及能够重新打开。六个面板会写入并恢复动画样式；减少动态效果模式不产生动画样式写入。快速切换标签后没有残留的隐藏内容或浏览器错误。
