# Agent Note: 上游整合时保留本地外壳

Status: implemented

[English](2026-09-16-local-shell-upstream-integration.md) | 中文

## 问题

本地应用导航和 Live Signal 使用旧版布局约定。上游现在拥有全局主面板、可停靠的右侧栏和根作用域覆盖层。直接合并而不适配这些约定会导致浏览器启动失败或隐藏本地页面。

## 决策

保留本地外壳作为 Web 根节点，通过 `ui-layout-core` 共享上游的几何计算、导航、状态和标题行为。保留上游的 `main`、`rightbar` 和根覆盖层席位。本地页面使用独立的会话可选 `shell.app-overlay` 席位，在未选择会话时也渲染。Live Signal 保留独立的纯图标折叠按钮。

保留本地 Apps、Knowledge、News、Skills、Experts、Styles、中文导航、受保护资源和蒸馏草稿。每个生成的 Remote 只挂载一次。在 base profile 中明确关闭会话日志上传。验证使用临时数据，不迁移用户现有会话。

## 考虑过的替代方案

直接使用上游根节点会移除已批准的本地导航和 Live Signal 行为。把上游布局实现复制到两个包中会重复状态与几何规则。

## 影响

两个布局提供方都依赖共享浏览器模块，组合必须先激活该模块。现有运行实例需要重新构建和启动才能使用合并后的源码。历史本地实施文档完整保存在用户 vault 附件中。

## 测试

定向集成测试覆盖本地面板、布局、工作区导航、受保护资源、应用进程、Knowledge 和 Ponytail。Remote 组装测试拒绝重复挂载，外壳回归测试验证未选择会话时本地覆盖层仍挂载。隔离浏览器验证运行完整 Web profile。Vault 整合报告记录构建、审计和文档检查的准确结果，包括尚未解决的既有文档欠账。
